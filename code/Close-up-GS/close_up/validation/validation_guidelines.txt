1. 数据准备要求
使用与官方完全一致的测试集（至少3组近景物体数据）
测试图像应包含不同材质（金属、布料、塑料等）和不同光照条件
每组数据必须包含:原始输入图、官方参考渲染结果、官方深度图、官方细节区域标注

2. 定量指标合格标准
PSNR（峰值信噪比）: ≥25.0 dB（越高越好）
优秀: >28.0 dB
合格: 25.0-28.0 dB
  不合格: <25.0 dB

SSIM（结构相似性）: ≥0.85（越高越好）
  优秀: >0.90
  合格: 0.85-0.90
  不合格: <0.85

3D一致性: 相邻视角平均差异 <15.0
  差异计算方式: 相邻渲染图的像素绝对值平均差

细节保留: 边缘相似度 ≥0.75
边缘相似度: Canny边缘检测结果的匹配比例

3. 定性评估标准
视觉一致性: 复现结果与官方参考在整体观感上无明显差异
细节质量: 近景物体的纹理、褶皱、边缘等细节清晰可辨
3D完整性: 多角度渲染无明显穿帮、扭曲或漂浮现象
无异常 artifacts: 结果中不应出现明显的噪点、模糊或颜色偏移

  4. 综合通过标准
必须同时满足:
1. 所有定量指标达到合格线以上
2. 定性评估无明显缺陷
3. 在3组不同测试数据上均保持稳定表现

  5. 验证流程
1. 准备官方参考数据和你的复现结果
2. 运行validate_closeup_gs.py生成量化报告
3. 检查视觉对比图进行定性评估
4. 对照综合通过标准判断是否复现成功
5. 若未通过，根据报告提示调整参数重新运行
